# Imóvel Busca — Laboratório GeckoAPI

Laboratório experimental separado do Web Imóveis. A aplicação será publicada na Vercel, com importação de JSON e integração autenticada da GeckoAPI via função de servidor.

Não coloque chaves privadas no repositório. A consulta autenticada dependerá de variáveis de ambiente Vercel `GECKO_API_TOKEN` e `LAB_ACCESS_CODE`.
